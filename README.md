# Dinesh Finance Pro 2026 — Live Cloud

1. Run `supabase.sql` once in Supabase SQL Editor.
2. Upload `index.html`, `manifest.json`, and `sw.js` to the root of GitHub repo `KDINESH1057/dinesh-finance`.
3. Open the GitHub Pages URL and tap the cloud button to create/sign into your account.
4. On iPhone: Safari → Share → Add to Home Screen.

The browser uses the Supabase publishable key only. Never put a service_role/secret key in the website.
